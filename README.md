# 🎵 Spotify Music Disc Searcher

A professional, high-performance Angular application for searching music albums, viewing rich track details, and managing a personal collection with glassmorphism aesthetics.

## 🚀 Quick Start

### 1. Prerequisites
Ensure you have **Node.js** and **npm** installed on your machine.

### 2. Configuration (Crucial)
This app requires a Spotify Client Secret. 
1. Copy `src/environments/environment.secret.example.ts` to `src/environments/environment.secret.ts`.
2. Open the new file and paste your `spotifyClientSecret`.

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Development Server
```bash
npm start
```
Once the server is running, navigate to **`http://localhost:4200/`**.
